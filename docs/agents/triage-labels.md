# Triage labels

技能以五種標準 triage 角色描述 issue 狀態；本檔把角色對應到本 repo 實際使用的 label 字串。

| mattpocock/skills 的角色 | 本 repo 的 label | 意義 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 維護者需要評估 |
| `needs-info` | `needs-info` | 等待提出者補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可交給無人值守的 agent |
| `ready-for-human` | `ready-for-human` | 需要人類實作（例如 CLAUDE.md 規則 1 的政策變更） |
| `wontfix` | `wontfix` | 不處理 |

技能提到某個角色時（例如「套用 AFK-ready 的 triage label」），使用此表右欄的字串。要改用別的字串，直接修改右欄。

# Triage labels

The skills describe issue state with five canonical triage roles. This file maps each role to the label string this repo actually uses. If the two language sections disagree, the Traditional Chinese section prevails.

| Role in mattpocock/skills | Label in this repo | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate it |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation (for example, policy changes under CLAUDE.md rule 1) |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a role (for example, "apply the AFK-ready triage label"), use the string in the right-hand column. To use different strings, edit that column.
